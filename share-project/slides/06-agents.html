主流 Agent，先看它在哪里干活

“Agent”不是一个单一品类：有的在 IDE 里改代码，有的在终端或云端跑长任务，有的连接办公与企业系统。下面覆盖开发者最常遇到的国际与国内入口，不做排名。

CodingIDE / CLI / 云端办公 / 研究国内生态不做排名
先分清三个词模型 ≠ Agent ≠ 平台。 DeepSeek、通义千问、豆包、GLM 等首先是模型或模型服务；Copilot、Cursor、通义灵码、TRAE 等是把模型接上上下文、工具和审批流程的产品；Coze、Dify、LangGraph 等更偏 Agent 的构建与编排平台。

二、通用、办公与自托管 Agent

Agent形态 / 来源适合先试什么记住它的特点
通用工作 / 研究型｜搜索、读文件、分析资料、生成交付物
ChatGPT Work
官方说明 ↗		通用工作、研究与成品交付 Agent网页研究、文件处理、表格、报告和多步骤工作更适合非纯编码任务；登录、外部连接和高影响操作要保留人工接管
Kimi Agent
官方说明 ↗		面向个人工作的中文通用 Agent联网搜索、资料整理、文档、PPT、数据分析和规划文件、浏览器、终端等工具组合较丰富；事实和敏感数据仍需核验
QoderWork CN
官方说明 ↗		阿里云 Qoder CN 系列的办公 / 桌面 Agent办公自动化、文件处理、研究和企业内任务与 Qoder CN / 通义灵码同属产品系列，适合关注国内部署和企业合规的场景
办公套件 / 企业流程型｜把 Agent 接到组织知识、协作和权限体系
Microsoft 365 Copilot / Copilot Studio
官方介绍 ↗		微软的办公助手与企业 Agent 构建平台Teams、Word、Excel、Outlook、企业知识和流程自动化价值在 Microsoft 365 / Graph / 权限体系；企业要重点审查数据访问与治理
WorkBuddy
腾讯云介绍 ↗		腾讯的全场景桌面 AI 工作台办公、项目管理、交付和桌面操作更接近企业办公入口，重点看公司环境、数据和套餐政策
个人消息 / 自托管自动化｜从聊天入口召唤 Agent 操作自己的设备
Hermes
官方仓库 ↗		开源、可自托管的个人 Agent个人助理、消息渠道、记忆和自动化CLI / TUI + 消息网关 + 持久记忆和 Skills；密钥与渠道权限自己负责
OpenClaw
官方仓库 ↗		运行在自己设备上的开源个人 Agent聊天入口、设备协作、个人或团队自动化Gateway 连接多渠道，模型和 Harness 可插拔；权限要谨慎
Agent 构建 / 编排平台｜把模型、知识库、工具和流程组装成自己的助手
扣子 Coze
官方网站 ↗		面向 Bot / Agent 的搭建与发布平台知识库问答、工作流、客服和轻量应用重点是可视化编排、插件和发布渠道，不等同于单一模型或 Coding Agent
Dify
官方网站 ↗		开源的 LLM 应用与 Agent 编排平台企业知识库、RAG、工具调用和内部助手可自托管、接多模型和工具；上线前要自己做权限、日志和评测

按工作选择，不按热度选择

🧑‍💻 我主要做开发

先看 Codex / Copilot / Claude Code / Cursor，国内可试 Qoder CN / TRAE / CodeBuddy / Comate；重点比较代码库理解、测试闭环、权限和模型来源。

⏳ 我需要长任务

先看 Devin / OpenHands / Prime Agent / Codex，也可试 Kimi Code / Qwen Code；重点比较后台运行、沙箱、记忆、子 Agent 和人工接管。

🏢 我关心国内与企业合规

先看 CodeBuddy / Comate / Qoder CN / CodeArts / CodeGeeX；重点核对地区可用性、私有化、知识库、审计、账号和数据是否出域。

📋 我主要做办公、交付、咨询

先看 ChatGPT Work / Kimi Agent / Microsoft 365 Copilot / WorkBuddy；要搭自己的助手，再看 Coze / Dify / Hermes / OpenClaw。

⚠️ 选型提醒这张表是“认识地图”，不是产品排名。版本、模型支持、价格、地区和公司策略都会变化；真正选型时先拿自己的任务做小范围验证。
🎙 讲师提示（约 3–4 分钟）

“这一页先把地图补全：Coding Agent 里有 Codex、GitHub Copilot、Claude Code、Cursor、Windsurf，也有 Cline、OpenHands、OpenCode、Pi 这样的开源入口；国内则有 Kimi Code、Qwen Code、Qoder CN、TRAE、文心快码、CodeBuddy、CodeGeeX 和 CodeArts。”

“注意 Copilot 有两条常见产品线：GitHub Copilot 主要服务软件研发，Microsoft 365 Copilot / Copilot Studio 主要服务办公与企业流程。通义灵码也正在升级到 Qoder CN 系列，MarsCode 插件则已更名为 Trae Plugin，看到旧资料时要能对上号。”

“大家不要逐行背功能，也不要直接问谁最好。先问自己的任务是什么：要改代码，跑长任务，还是连接办公系统？国内和企业环境还要把网络、数据、私有化和审计一起纳入选型。”

“模型、Agent 产品和编排平台也要分开看：同一个模型可以被多个 Agent 使用，同一个 Agent 也可能支持多家模型。最终仍然要在自己的任务、权限和安全边界里做小范围验证。”
