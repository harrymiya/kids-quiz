42–46′ · 产品速览：不做排名

市面上的 Agent，不是一个赛道

先按形态理解，不急着比较谁最好：有的专注 Coding，有的擅长长任务和多 Agent，有的更像个人或办公工作台。

Coding长任务个人 / 办公不做排名
Agent一句话定位适合先试什么记住它的特点
Pi
官方资料 ↗		开源、终端型 Coding Agent读项目、改代码、写脚本多模型切换，强调可扩展的 Agent Harness
OpenCode
官方文档 ↗		开源 Coding Agent终端、桌面或 IDE 里的开发任务可接不同模型供应商，适合想保留选择权的团队
Prime Agent
官方仓库 ↗		面向长任务的开源 Coding / Research Agent长时间调研、评测、复杂工程任务持久 REPL、子 Agent、目标和后台运行；权限边界要单独做
Codex
官方介绍 ↗		面向工程交付的 Coding Agent开发、重构、测试、代码审查和 CI覆盖 ChatGPT、编辑器和终端，可做端到端工程任务
Claude Code
官方文档 ↗		Anthropic 的 Coding Agent理解代码库、修 Bug、改多文件、跑命令终端、IDE、桌面和浏览器都可用，适合深度代码协作
Hermes
官方仓库 ↗		开源、可自托管的个人 Agent个人助理、消息渠道、记忆和自动化CLI / TUI + 消息网关 + 持久记忆和 Skills
OpenClaw
官方仓库 ↗		运行在自己设备上的开源个人 Agent聊天入口、设备协作、个人或团队自动化Gateway 连接多渠道，模型和 Harness 可插拔；权限要谨慎
WorkBuddy
腾讯云介绍 ↗		腾讯的全场景桌面 AI 工作台办公、项目管理、交付和桌面操作更接近企业办公入口，重点看公司环境、数据和套餐政策

按工作选择，不按热度选择

🧑‍💻 我主要做开发

先看 Codex / Claude Code / OpenCode / Pi；重点比较代码库理解、测试闭环、权限和模型来源。

⏳ 我需要长任务

先看 Prime Agent / Hermes / OpenClaw；重点比较后台运行、记忆、子 Agent 和人工接管。

📋 我主要做交付、PM、咨询

先看 WorkBuddy / Hermes / OpenClaw，再按实际工具连接和数据边界决定。

⚠️ 选型提醒这张表是“认识地图”，不是产品排名。版本、模型支持、价格、地区和公司策略都会变化；真正选型时先拿自己的任务做小范围验证。
🎙 讲师提示（约 3–4 分钟）

“市面上的 Agent 不是一个赛道。Pi、OpenCode、Codex、Claude Code 更偏开发；Prime Agent 更偏长任务和研究；Hermes、OpenClaw 更像可自托管的个人 Agent；WorkBuddy 更接近办公和桌面工作台。”

“大家不要背功能，也不要直接问谁最好。先问自己的任务是什么：要改代码，还是跑长任务，还是连接办公系统？”

“产品变化很快，所以这张表只帮助大家建立地图。最终还是要在自己的网络、模型、权限和安全边界里试一次。”
