# 奇趣知识岛

面向小学生的多学科肉鸽答题闯关项目（覆盖小学 1–6 年级全教材单元）。

## 技术栈

- React + Vite
- Express
- SQLite（Node.js `node:sqlite`）
- Web Audio API
- OpenAI 兼容大模型网关（AI 老师 / 学情分析 / 专属出题 / 模型探测）

## 启动

```bash
npm install
npm run dev
```

前端地址：`http://localhost:5173`
后端地址：`http://localhost:8787`

## 功能

- 六大学科、400+ 知识点，对齐人教数学 / 部编语文 / PEP 英语 / 教科科学 / 部编道法 1–6 年级上下册单元，200+ 考纲精题 + 大模型按目录无限出题
- 一～六年级分级，热身、进阶、挑战三档难度
- 5、8、10、12 道题量设置，5 层肉鸽式答题闯关与随机增益
- SQLite 个人档案和作答记录：每题记录知识点、选项快照与讲解
- 间隔复习记忆曲线：1、3、7、14、30 天，到期复习题优先组卷
- 🗺️ 知识星图：每个知识点是一颗星，掌握即点亮，可按学科 / 年级 / 上下册筛选，点击星星直达专练与视频（只读当前档案）。
- 📕 错题本：答错自动归集，巩固答对自动毕业，可一键重练
- 🤖 学习 Agent：先读取真实学情 / 错题 / 课程目录，再自主规划并调用专练、错题本、知识星图、视频和庆祝等受控工具，执行轨迹可见
- 🧰 Agent 工具工坊：按孩子薄弱点创建并持久化练习卡、闪卡、反思卡和记忆卡，可在 AI 老师页反复调用
- 🤖 AI 学情分析：统计 + 大模型定性分析，给出强项 / 薄弱点 / 本周目标 / 家长建议（按一二习惯、三四方法、五六综合分段），并按薄弱点自适应推题
- 🎙️ AI 老师语音对话：speech to speech（语音识别 + 语音播报），可连续对话、讲错题、陪练
- 🧑‍🏫 答错即时讲解：每题自带儿童版讲解，可朗读、可一键问 AI 老师

## 大模型接入

后端直连 OpenAI 兼容网关。**模型不写死**：到前端「设置」页从实时模型列表里选择并保存（存 SQLite 数据库，重启不丢失，不进 Git），或用环境变量配置：

```bash
LLM_BASE_URL=https://... LLM_API_KEY=sk-... LLM_MODEL=你选的模型 LLM_FALLBACKS=兜底模型A,兜底模型B npm run dev
```

- 设置页可「刷新模型列表」「🔍 自动找可用模型」（实测出当前有通道的模型并保存）。
- 网关按“模型×分组”动态分配通道：所选模型无通道时，按你配的兜底模型自动切换；都没配或都不可用时会明确提示。
- 大模型不可用时自动降级为本地题库与本地统计，不阻断学习。
- Agent 只可调用后端白名单工具，参数会裁剪和校验；不开放任意代码、SQL、Shell 或系统访问。每轮最多调用 4 个工具，并记录执行轨迹。
